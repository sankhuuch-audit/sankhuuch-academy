# Ганзо Сургалт

**academy.sankhuuch-audit.mn** нь нягтлан бодогч, санхүүчдэд зориулсан төлбөртэй сургалтын хувийн сайт.
Сайт нь сургалтыг танилцуулж, бүртгэл хүлээн авна. Хичээлийн бичлэг сайт дээр байрлахгүй,
зөвхөн төлбөр төлсөн суралцагчид Google Classroom-оор хандана.

## Сургалт нэмэх, засах (Pages CMS)

1. [app.pagescms.org](https://app.pagescms.org) руу GitHub хаягаараа нэвтэрч `sankhuuch-academy` төслийг сонгоно.
2. **Сургалтууд** → **Add an entry** (шинэ сургалт) эсвэл байгаа сургалтаа нээнэ.
3. Нэр, товч тайлбар, төлөв, төлбөр, хугацаа, хөтөлбөр, багшийн мэдээллийг бөглөөд **Save** дарна.
4. Сайт 1-2 минутын дотор автоматаар шинэчлэгдэнэ.

- **Бүртгэлийн төлөв**: «Бүртгэл нээлттэй» үед бүртгэл авна. «Удахгүй» үед урьдчилсан бүртгэл авна.
  «Бүртгэл хаагдсан» үед сургалт жагсаалтын доод хэсэгт харагдаж, бүртгэлийн маягтад гарахгүй.
- **Ноорог** сонговол сургалт сайт дээр харагдахгүй.
- «Жишээ: …» нэртэй сургалт нь ноорог загвар. Хэрэггүй бол устгаж болно.
- Төлбөртэй хичээлийн бичлэгийн холбоосыг сайтад **оруулахгүй**. «Танилцуулга бичлэг» талбарт зөвхөн үнэгүй үзүүлэх богино бичлэг тавина.

## Бүртгэл хэрхэн ажилладаг вэ

1. Суралцагч `/burtguuleh/` хуудасны маягтыг бөглөнө.
2. Бүртгэл «Ерөнхий тохиргоо»-ны имэйл хаягт «Сургалтын бүртгэл: …» гарчигтай имэйлээр ирнэ
   (FormSubmit үйлчилгээгээр, үнэгүй). Имэйлийн **Reply** дарахад суралцагч руу шууд хариу бичигдэнэ.
3. Суралцагч руу төлбөрийн нэхэмжлэх (дансны дугаар эсвэл QPay) илгээнэ.
4. Төлбөр орсны дараа суралцагчийн Google хаягийг Google Classroom-ийн ангид урина.

## Google Classroom тохируулах

1. [classroom.google.com](https://classroom.google.com) → **+** → **Create class**. Сургалт бүрт нэг анги үүсгэнэ.
2. **Бичлэгийг Google Drive-д байршуулна.** YouTube-д «Unlisted» байдлаар тавьсан бичлэгийг холбоос мэдсэн хэн ч үзэж чадна.
   Drive дахь файлын хандалтыг «Restricted» (анхдагч) хэвээр үлдээнэ, «Anyone with the link» болгохгүй.
3. Ангийн **Classwork** → **Create** → **Material** → Drive-аас бичлэгээ хавсаргана. Ингэхэд зөвхөн ангийн гишүүд үзэх эрхтэй болно.
4. Drive дахь файлын хуваалцах тохиргооны ⚙ хэсгээс «Viewers and commenters can see the option to download, print, and copy»
   сонголтыг унтраавал татаж авах товч харагдахгүй.
5. **People** → **Invite students** → суралцагчийн бүртгэлд бичсэн Google хаягийг оруулна. Урилга түүний имэйлд очно.
6. Бичлэг үзэх хугацаа дууссан суралцагчийг **People** хэсгээс хасна.

## Техникийн мэдээлэл

- Сайтыг [Eleventy](https://www.11ty.dev/) 3 бүтээж, GitHub Actions-ээр GitHub Pages дээр байршуулна (үнэгүй).
- `src/content/courses/` — сургалтууд (Markdown), `src/_data/` — тохиргоо, түгээмэл асуулт.
- `src/assets/css/site.css` нь үндсэн загвар, `academy.css` нь сургалтын сайтын нэмэлт загвар.
- Бүртгэлийн маягтын скрипт: `src/assets/js/register.js`.

```sh
npm ci          # хамаарлуудыг суулгах
npm start       # http://localhost:8080 дээр турших
npm run preview # ноорог сургалтуудыг оролцуулан турших
npm run build   # _site хавтсанд бүтээх
```
